Under the hood

Native Win32.
Nothing borrowed.

Zero Electron bloat, no Chromium or Node.js runtime. Built in pure native C++ with the Win32 API and GDI+, communicating directly with Windows.

Stays on top

A quiet 250ms timer re-asserts HWND_TOPMOST, so Windows never buries it behind other windows.

Survives taskbar previews

Intercepts WM_SHOWWINDOW to veto SW_PARENTCLOSING, so hovering an open app can't hide it by accident.

Works 100% offline

Converts and renders the Bikram Sambat date locally on your machine — zero network requests, tracking, or internet connection needed.

Syncs with Windows live

Listens for WM_SETTINGCHANGE and repaints the instant you flip Light or Dark mode.

Ultra-efficient by design

It checks the clock.
It doesn't watch it.

Once a second, the widget asks Windows for today's date — a near-zero-cost call. Only when the day actually changes does it run the Bikram Sambat conversion and repaint.
